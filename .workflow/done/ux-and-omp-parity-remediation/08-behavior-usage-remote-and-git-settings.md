## Resolution

**Superseded decision.** The blocker recorded that the four Commit Message Generation controls never existed upstream and could only be built as new features. The maintainer reviewed that finding and explicitly chose option (b): implement them end to end rather than reword the spec. The source-gap evidence is still accurate and is kept in the task history; it is no longer a reason to stop.

**Design (one canonical key per control, no aliases):**

- `packages/ui/src/lib/gitCommitSettings.ts` is the single owner of defaults and of the live value: `generateCommitMessages` (true), `commitMessageReasoning` (false), `commitMessageNotes` (false), `commitMessageChangeId` (false). Consumers read it through `useCommitSettings`, which hydrates from `loadDesktopSettings` and follows `openchamber:settings-synced`.
- Generation gate: `CommitSection` hides only the generate action when the setting is off; `GitView` and `MobileChangesSurface` both refuse to start a generation (including the dirty-branch-switch path) while leaving the manual commit input and both commit buttons unchanged.
- Reasoning: `SmallModelRequest.reasoning` makes `requestSmallModel` send the effort the resolved model actually advertises (`medium` when offered, else its first level), and `null` otherwise, so a model without reasoning support is never refused for an invented effort.
- Git notes and Change-Id: `CreateGitCommitOptions` carries both flags; the Host commit route validates them as booleans. `git/service.js` applies them inside `withGitIndexMutationQueue` after the commit exists, Change-Id first (reusing `source-control/change-id.js` via `addChangeIdToHead` with `requireClean: false`, plus a new `readCommitChangeId`), then a `git notes add -f` on the final SHA. An existing trailer is answered, never amended twice; a failed extra throws `COMMIT_EXTRAS_FAILED` naming the commit that exists, which the route returns as a 409 body and both UIs report as a warning instead of success.
- Locale: the new keys live in the already-merged git module `git-identity-editor.i18n.ts`, translated in all 15 locales, so no dictionary owned by another window was edited.
