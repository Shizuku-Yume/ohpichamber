# OpenChamber v2.7.0 UI/UX alignment, OMP TUI fidelity, and streaming/runtime performance remediation (22-point review)

**Status:** in progress
**Priority:** high
**Integration branch:** ux-v270-omp-alignment/integration

## What this is for

Maintainer side-by-side inspection of OhPiChamber (`e6b8cfd65b`) against upstream OpenChamber `v2.7.0` (`bc50ba56a`) and standalone OMP TUI (`18.18.0` / `vendor/omp/b5a6b2f7`) across 34 screenshots identified 22 concrete product, UI/UX, streaming, tool-integration, and performance defects:

1. **Sidebar & Settings Divergence from OpenChamber `v2.7.0` (#1, #22):** `SidebarHeader.tsx` inverted the 4-button toolbar (`[Search] [Folder+] [Filter] [...]`), dropped `SectionsManager` (`自定义分区…`), `MarkAllReadItem` (`全部标为已读`), and `worktreeNameByBranch`, and scattered secondary views inline; `DesktopAppSettings.tsx` injected a broken unselectable `"运行状态 Bundled (default)"` row above `"保存并重启"`; `GeneralWorkspaceSettings.tsx` (`文件与编辑器` with segmented `[默认 | Vim]`, `文件树位置 [左侧 | 右侧]`, `显示点文件`, `以预览模式打开可预览文件`), `ThemeAppearancePicker.tsx` + `ThemeSchematic.tsx`, `OpenChamberToolsSettings.tsx` flattened groups, `KeyboardShortcutsSettings.tsx` tidied toolbar, `AboutReleaseNotes.tsx`, and `ProviderLogoImageControl.tsx` were left unmerged among 585 `adapt-pending` paths and 68 `v2.7.0` commits.
2. **Broken Running Session Animation Toggle (#2):** Enabling `"运行中会话的动画指示器"` (`animatedActivityIndicators`) has zero visual effect because `SessionActivityIndicator.tsx` renders `.activity-spinner` without `animate-spin` or any `@keyframes` rule in CSS.
3. **Disconnected Usage Page vs Token Analytics (#3):** `UsagePage.tsx` (`Settings → 用量`) queries `/api/quota/*` without reading OMP credentials (`~/.omp/agent/auth.json`), showing 26 unconfigured providers and broken legacy guidance while hiding the working `UsageStatsView.tsx` token analytics (`Token 明细 / 每日用量 / 按模型分布 / 按项目分布`).
4. **Regressed Web Search Settings & False Enterprise Warning (#4):** `WebSearchPage.tsx` replaced upstream's segmented `[默认 | 任意提供商 | 关闭]` and 5 provider cards (`无需密钥即可使用`) with stacked `备用提供商` dropdowns and falsely displayed `"企业策略阻止搜索请求..."` on keyless providers because `canWrite = provider.credentialWritable && !enterprise` fell into the enterprise message whenever `credentialWritable` was `false`.
5. **UI & Runtime Performance Bottlenecks (#5):** `OmpSettingsPage.tsx` mounts all 10 tabs and 158 un-memoized settings simultaneously (`className="hidden"`), freezing 600–1200ms and re-rendering all rows per keystroke; new session creation spawns a cold Bun subprocess (`400–800ms`) and blocks first-turn dispatch on an IPC→HTTP→IPC `provider.use` loopback; `GET /models` and `GET /providers` reload disk YAML/JSON and re-run model policies on every call with zero Host/worker cache while multiple UI callers bypass `useConfigStore`.
6. **OMP Settings Bloat, TUI-Only Leakage, Raw Controls & Missing i18n (#6, #8, #10):** `OmpSettingsPage.tsx` exposes terminal-only settings (`Shell Visualization`, `Colorful Markdown`, `Max Frames Per Second`, `Motion`, `Spinner Interval (ms)`, `renderMermaid`, `renderSvg`, `autoGraph`) with untranslated English strings, invented non-TUI raw `config.yml` editors (`enabledModels`, `cycleOrder`, `modelPresets`, `thinkingBudgets.*` steppers), and 16 bloated `Model Roles` cards using raw `<Select>` instead of `PATTERNS.md` `SettingsFieldRow` + shared `ModelSelector`.
7. **Duplicate Agent Tool Controls (#7):** `AgentsPage.tsx` renders a 30-checkbox grid immediately above a duplicate legacy `<ul>` tag list with `x` buttons and manual text input.
8. **Polluted Commands Page (#9):** `CommandsPage.tsx` dumped 29 read-only OMP CLI runtime action commands (`/clear`, `/compact`, `/effort`, `/fast`, `/jobs`, `/cleanse`) with English descriptions instead of upstream's prompt-template slash command editor (`.omp/commands/*.md` & `~/.omp/agent/commands/*.md`).
9. **Cramped OMP Plugins Page & Broken Install (#11):** `PluginsPage.tsx` (`ExtensionControlCenter.tsx`) renders a cramped 21-pill toggle wall and raw 3-column inspector with broken plugin installation instead of a clean `SkillCatalogPage`-style Installed / Marketplace / Capability Sources layout.
10. **Composer Mode Search & Synthetic Effort Default (#12):** `ComposerModeSelector.tsx` renders a `搜索模式` search box inside a 4-item menu (`主模式 / 计划 / Vibe / 目标`), and `ThinkingPill.tsx` / `DefaultsSettings.tsx` inject a synthetic `"默认"` (`""` / `"__default__"`) option instead of defaulting directly to `'medium'` (or the model's concrete default level).
11. **Composer Permission Shield Desync (#13):** Setting global Tool Permission Default Mode to `"全部批准"` (`auto`) leaves the chat composer shield stuck on `"要我批准"` (`ask`) because drafts hardcode `'ask'` and `usePermissionStore` / `subscribePermissionPolicySync` is never hydrated on app startup.
12. **Broken Next-Prompt Suggestions, AI Rename & Title Sync (#14):** `"生成下一条用户建议"` waits 60s and is immediately purged by `assist.generatedAt >= session.updatedAt`; `"重新生成标题"` (`AI Rename`) is disabled whenever `modelRoles` include `:thinkingLevel` suffixes in `smallModelRequest.ts`; `session.updated` title events are dropped by `event-reducer.ts` / `sync-context.tsx` when a brand-new session is not yet in `next.session`, and `scheduleAutoTitle` in `worker/session.ts` permanently aborts on second-prompt races.
13. **Transparent Composer Input Bleed-Through (#15):** `ChatInput.tsx` applies `.oc-glass-composer`, which has no surface background rule in `design-system.css`, letting scrolling messages, tool cards, and todos bleed directly behind typed input text.
14. **Uncollapsible Todo Tray & Non-Streaming Thinking/Text Output (#16):** `TodoTray.tsx` permanently expands all phases/tasks with no collapse toggle instead of defaulting to collapsed with active-item preview; thinking traces and prose pop out only after paragraph/block completion because `expandReasoningWhileStreaming` defaults to `false`, `commitStreamedText` holds up to 1,500 chars until `\n\n`, `ReasoningPart.tsx` buffers through `commitStreamedText`, and `MessageList.tsx` `tailMessageIds` omits tool-result messages during multi-step turns.
15. **Whimsical Status Phrases & Missing OMP Tool Intent (#17, #18):** `useAssistantStatus.ts` hashes `sessionId` into whimsical phrases (`calibrating` → `"正在校准"`) instead of OMP TUI's deterministic `Working…` / thinking status / `input.i` intent; `toolDescription()` in `toolHelpers.ts` omits `todo` completely (rendering bare `🛠 todo`), ignores `input.i`, and omits match/file/diff result summaries.
16. **Missing Inline Artifact Rendering (`openchamber_render`) & Missing Turn Telemetry / Polluted Context Modal (#19, #20):** `openchamber_render` (`render.page`) was omitted from `native-policy-protocol.ts` and `worker/host-tool.ts` while `TurnPagesRow` in `LiveTurnActivity.tsx` is a `{part.type}` stub; `telemetry.ts` hardcodes `tok/s`, `totalLlmDurationMs`, `totalToolDurationMs`, and `avgTtftMs` to `null`; `projection.ts` emits `toolResult` as `role: 'system'` (`system: todo`) and empty virtual `user:` rows while `ContextSidebarTab.tsx` lacks upstream `contextBreakdown.ts` (`系统与工具`) accounting.
17. **Integrations Catalog Install Failure (#21):** Installing or connecting any MCP integration in `IntegrationsCatalogView.tsx` fails 100% of the time with `"SDK worker operation failed"` due to a circular authorization deadlock in `StatelessWorker` (`stateless.ts:126` calling `authorize({ type: 'mcp-server' })` before writing `.omp/mcp.json`, rejected by `worker-operation-authorizer.js:95` because the new server is not yet on disk, and masked by `WorkerOperationError`'s default message in `supervisor/workers.ts:919`).

## What it does

- **Task 01 (`01-mcp-install-and-runtime-perf`):** Eliminates the circular `mcp-server` authorization check on `StatelessWorker` MCP config persistence, relaxes `worker-operation-authorizer.js` server matching so enabling/connecting MCP servers succeeds, forwards worker error `detail` into `WorkerOperationError`, adds a pre-warmed idle session worker in `WorkerRegistry` + bootstrap-seeded authorized `providers` in `WorkerSession`, adds revision-invalidated model/provider catalog caching across `CatalogCoordinator` / `catalog-models.ts`, routes UI model readers through warm `useConfigStore`, strips `:thinkingLevel` suffixes in `smallModelRequest.ts`, and hardens `WorkerSession.scheduleAutoTitle` against second-prompt abort races.
- **Task 02 (`02-sidebar-header-and-activity-spinner`):** Aligns `SidebarHeader.tsx` and session sidebar controls with OpenChamber `v2.7.0` (`[Search] [Folder+] [Filter/Equalizer] [...]`, `SectionsManager` `自定义分区…`, `MarkAllReadItem` `全部标为已读`, `worktreeNameByBranch`, right-click row menus, worktree icon, secondary views inside `[...]`), and fixes `SessionActivityIndicator.tsx` so `animatedActivityIndicators` spins live running indicators.
- **Task 03 (`03-general-appearance-and-settings-v270`):** Removes the fake `"运行状态 Bundled (default)"` row from `DesktopAppSettings.tsx`, adopts OpenChamber `v2.7.0` `GeneralWorkspaceSettings.tsx` (`文件与编辑器` with segmented `[默认 | Vim]`, `文件树位置 [左侧 | 右侧]`, `自动保存文件`, `移动文件前确认`, `显示点文件`, `以预览模式打开可预览文件`), `ThemeAppearancePicker.tsx` + `ThemeSchematic.tsx` (retiring legacy `ThemePicker.tsx`), `OpenChamberToolsSettings.tsx` flattened groups, `KeyboardShortcutsSettings.tsx` toolbar, and `AboutReleaseNotes.tsx`, and prunes legacy duplicate sections from `OpenChamberVisualSettings.tsx`.

## How it is built

- **Retained Runtime Surfaces (`ui-api-decoupling`):**
  - **Web / PWA:** Full Canonical API (`/api/agent/v1`) + Host routes (`/api/openchamber/render/answer`, `/api/quota/*`, `/api/permission-auto-accept/*`), full `v2.7.0` UI/Settings/Chat parity.
  - **Electron Desktop:** Same in-process Node Host Gateway + Bun Agent Service with pre-warmed worker pool; `DesktopAppSettings.tsx` cleanly manages native shell windowing without fake runtime rows.
  - **Hosted Mobile & Capacitor Mobile:** Uses shared mobile sheets/drawers (`ComposerModeSelector` mobile sheet without search box, collapsible `TodoTray`, `MobileStatusPane`, `UsagePage` analytics, responsive `PATTERNS.md` settings) with zero local subprocess assumptions.
- **Strict Boundary & Visual Discipline:** All agent execution and native OMP catalogs stay behind `@openchamber/agent-contract` and `/api/agent/v1`; all UI and Settings surfaces strictly follow `packages/ui/src/components/sections/PATTERNS.md`, `packages/ui/src/lib/theme/STYLING.md`, and upstream `v2.7.0` component composition; all new/updated strings include real translations across all 15 locale dictionaries.

## What it must not do

- Reintroduce OpenCode runtime dependencies or the retired VS Code extension.
- Expose terminal-only OMP TUI rendering flags (`Shell Visualization`, `Max FPS`, `Colorful Markdown`, `Spinner Interval`) or raw JSON/YAML config steppers in GUI Settings.
- Buffer live thinking traces behind multi-paragraph `commitStreamedText` holds or block MCP config writes on pre-persistence runtime policy checks.
