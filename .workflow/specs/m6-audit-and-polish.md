# M6: Full-codebase audit, OpenChamber UX restoration, missing OMP capabilities, and UI compliance

**Status:** done
**Priority:** high
**Integration branch:** m6-audit-and-polish/integration

## What this is for

Across earlier migration efforts (`omp-through-m3`, `upstream-refresh`, `omp-native-chat`, `omp-native-parity`, and `m4-orchestration`), three systemic quality gaps accumulated:
1. **Dogmatic feature cuts:** Genuine OpenChamber frontend/Host capabilities (cross-device `session-pins`, persistent `session-unread` watermarks + turn duration badges + tray/dock/widget sync, `BehaviorPage` response-style presets and `AGENTS.md` editor, `DesktopAppSettings` separation, `DefaultsSettings` pickers, and 6 General/Chat/Passkey/Worktree controls) were deleted or degraded simply because the standalone OMP CLI had no 1:1 field or under overly rigid prompt-purity rules.
2. **Unwired OMP capabilities:** High-value capabilities built into pinned OMP `18.16.0` (`vendor/omp/650f3a10`)—native `IdleMaintenance` session `Recap` (`session_recaps` in `history.db` + `SessionRecapSpacer.tsx`), `Agent Hub` swarm coordination (`modes/agent-hub-runtime.ts`, `registerPersistedSubagents`, `subagent.revive`, transcript viewer, `sumSubagentTreeCost`), full-lifecycle plugin `Marketplace` (`MarketplaceManager` source management, browse/install tab in `AddPluginDialog.tsx`, update checks/upgrades), and `@oh-my-pi/omp-stats` SQLite analytics (`stats.db`)—remained unwired or partially wired.
3. **Substandard UI craftsmanship & runtime route regressions:** Live browser inspection and static audits revealed that `/api/agent/v1/workspaces/:workspaceId/omp/settings` returns HTTP `404 NOT_IMPLEMENTED` (leaving `OmpSettingsPage.tsx` blank at runtime), `JobsSheetDialog.tsx` and `BackgroundShellsStrip.tsx` use non-existent Tailwind classes (`bg-surface-1/2/3`) and hardcoded palette colors (`bg-emerald-500`, `bg-rose-500`), and newly authored or rewritten Settings and Chat surfaces (`ProvidersPage.tsx`, `WebSearchPage.tsx`, `OmpSettingsPage.tsx`, `RoutingPage.tsx`, `PluginsPage.tsx`, `McpPage.tsx`, `CommandsPage.tsx`, `PermissionActions.tsx`, `PlanReviewCard.tsx`, `SessionRecapSpacer.tsx`, `CommandAutocomplete.tsx`, and 17 files with physical RTL classes) violate `packages/ui/src/components/sections/PATTERNS.md`, `packages/ui/src/lib/theme/STYLING.md`, and `locale-ui-patterns`.

The Phase 1 three-pillar read-only audit (`01`–`03`) is complete and archived in:

## What it does

### Pillar A — Restore Mistakenly Cut/Degraded OpenChamber Frontend & Host UX (`List A`)

1. **Cross-Device Session Pins (`#1 session-pins`):**
   - Restore `pinned: { at: number }` in `@openchamber/agent-contract` (`operationalSchema` / `operationalPatchSchema`) and `OPENCHAMBER_KEYS` in `packages/web/server/lib/openchamber-sessions/session-metadata-store.js` (`host-metadata.sqlite`).
   - Broadcast `openchamber:session-metadata` over `/api/openchamber/events` SSE when pins change.
   - Restore `packages/ui/src/sync/session-pins.ts` (`toggleSessionPin`, `pinQueues`, `setPendingPin`, legacy `localStorage` migration) and `setSessionPinned` in `session-actions.ts`, deriving `useSessionPinnedStore` authoritatively from server metadata so Desktop, Web, and Mobile stay synchronized.
2. **Persistent Session Unread Watermarks, Turn Duration Badges & Tray/Dock/Widget Sync (`#2 session-unread` + `#3 turn-duration`):**
   - Persist `openchamber.workbench = { lastIdleAt, viewedAt, lastTurnOutcome }` and `openchamber.turn = { endedAt, durationMs }` in `host-metadata.sqlite`.
   - Subscribe Host Gateway to Canonical `run.started`, `run.completed`, and `run.failed` events to record `lastIdleAt`, `lastTurnOutcome`, and `durationMs = finishedAt - startedAt`, broadcasting `openchamber:session-metadata` over SSE.
   - Restore `packages/ui/src/sync/session-unread.ts` (`isSessionUnread`, `markSessionUnreadSeen`) and re-bind `SessionSidebarItem.tsx`, `MobileSessionRow.tsx`, `SessionTabsStrip.tsx`, `sessionTurnMetadata.ts` (sidebar turn duration badge), `packages/electron/tray.mjs`, `packages/electron/dev-dock-identity.mjs` (`desktop_set_badge_count`), and `packages/ui/src/apps/mobileWidgetSnapshot.ts`.
3. **Response-Style Presets & Project `AGENTS.md` Rules Editor (`#4 BehaviorPage.tsx`):**
   - Restore `packages/ui/src/components/sections/behavior/BehaviorPage.tsx` under the `agent` Settings group, including response-style presets (`default`, `concise`, `detailed`, `mentor`, `pushback`, `noFiller`, `matchEnergy`, `warmPeer`, `custom`) and the `AGENTS.md` / global rules editor.
   - Enforce **strict `default` zero-injection**: when `default` (or unset) is active, send **0 bytes** of extra instructions (no `<system-reminder>`, no prompt mutation). When the user explicitly selects a non-default preset, deliver the style instruction cleanly via Canonical session/prompt system options without mutating user message transcripts.
4. **Restored OpenChamber Settings Sections & Controls (`sections/openchamber/*`):**
   - **Split `DesktopAppSettings.tsx` from `DesktopNetworkSettings.tsx`:** Restore a dedicated `DesktopAppSettings.tsx` (window chrome, launch at login, minimize to tray, macOS menu bar, Linux native frame, keep awake, mini-chat shortcut, Quake mode) separate from `DesktopNetworkSettings.tsx` (port, bind address, pairing), and restore `desktopRestartDrafts.ts`.
   - **Restore `DefaultsSettings.tsx` & Deduplicate `OpenChamberPage.tsx`:** Remove the duplicate `<DefaultsSettings />` render from the General tab (`OpenChamberPage.tsx:56`), keeping it on the Sessions tab (`OpenChamberPage.tsx:203`), and restore Default Model (mapped to OMP `default` role), Default Thinking Effort, and Default Session Mode (`main` / `plan` / `vibe` / `goal`) pickers alongside session deletion confirmation and sidebar toggles.
   - **Restore 6 Dropped UI Controls (Backing Stores Already Intact):**
     - `MobileWorkspaceTabsSettings.tsx` (drag-to-reorder mobile bottom bar tabs).
     - `worktreeArchiveOnDoneEnabled` checkbox in `MergedWorktreeCleanupSettings.tsx`.
     - `liveBrowserTabLimit` (1–20) stepper in `GeneralWorkspaceSettings.tsx` / `OpenChamberVisualSettings.tsx`.
     - Inline Passkey label rename button & input (`renameStoredPasskey`) in `PasskeySettings.tsx`.
     - `mobileReturnKeySends` and `savePastedImagesAsFiles` toggles in `ChatSettings.tsx`.
5. **Chat & Composer Parity Polish (`CP-04`, `CP-05`, `CP-06`):**
   - Ensure the Composer Compact action invokes the Canonical compact RPC (`session.compact()`) directly, text attachments inline cleanly with delimiters while binary/large attachments pass filesystem paths for `read`, and `useAssistantStatus.ts` maps OMP native tool names (`bash`, `task`, `ask`, `find`, `grep`, `glob`, `todo`).

### Pillar B — Wire Missing OMP `18.16.0` Capabilities (`List B`)

1. **Native OMP `IdleMaintenance` Session `Recap` & Rich Compaction Summary (`SessionRecapSpacer.tsx`):**
   - Enable `session.enableIdleMaintenance({ isBlocked, scheduledTurn, onRecap })` in `packages/agent-service/src/worker/session.ts` so quiet sessions run OMP's native ephemeral recap turn (`prompts/system/recap-user.md`), persist recaps in SQLite `history.db` (`session_recaps`), and emit Canonical `{ type: 'session.recap', sessionId, recap, createdAt }`.
   - Expose `GET /api/agent/v1/sessions/:id/recaps` (via `listSessionRecaps`) and register `recap.enabled` / `recap.idleSeconds` in settings schemas.
   - Update `SessionRecapSpacer.tsx` (`SessionRecapNote` and `CompactionDivider`) to render `session.recap` immediately (removing the redundant 60s client delay) and display full compaction metadata (`method`, `tokensBefore`, `tokensAfter`, `summary`), retiring the legacy `packages/web/server/lib/session-assist/` small-model polling watcher.
2. **OMP `Agent Hub` Swarm Dashboard, Persisted Subagents & Revive (`modes/agent-hub-runtime.ts`):**

3. **Full-Lifecycle Plugin `Marketplace` (`extensibility/plugins/marketplace/*`):**

## How it is built

  Implementation is partitioned into orthogonal, file-disjoint worktree lanes executed concurrently in dedicated Ghostty + `tmux` `omp /vibe` windows, merging into `m6-audit-and-polish/integration` under `flock /tmp/m6-integration.lock`:
  1. **Lane 1 (Host Workbench & Session Sync — Pillar A1/A2):** `agent-contract/src/metadata.ts`, `session-metadata-store.js`, `openchamber-sessions/*`, `sync/session-pins.ts`, `sync/session-unread.ts`, `useSessionPinnedStore.ts`, sidebar/tab unread & turn duration badges, Electron tray/dock & mobile widget unread sync.

  3. **Lane 3 (OMP Native Capabilities: Recap, Agent Hub & Stats — Pillar B1/B2/B4):** `worker/session.ts` (`enableIdleMaintenance` + `registerPersistedSubagents` + `subagent.revive` + transcript & tree-cost routes), `worker/usage.ts` (`@oh-my-pi/omp-stats` `stats.db` cutover), `SessionRecapSpacer.tsx`, `AgentHubModal.tsx`, and retirement of `packages/web/server/lib/session-assist/`.

## What it must not do

- Restore genuine OpenCode-only shims or maintainer-excluded features: Host Goal Supervisor (`SessionGoalCheckerField.tsx`), Root Agent Persona Picker (`CP-01`), dual tool-permission mode switches (`PermissionDefaultModeField.tsx`), dead `Code Mode` toggle (`SET-09`), OpenCode Folder Trust (`opencode-trust/*`), per-session cache warming (`session-warming/*`), bundled `ripgrep` (`prepare-ripgrep.mjs`), or OpenCode CLI scripts/proxies.
- Inject any prompt text, `<system-reminder>`, or hidden instructions when `BehaviorPage` response style is set to `default` (or unset).
- Ship unstyled or test-only forms, viewport breakpoints (`sm:`/`md:`/`lg:`) inside settings panes, fake Tailwind utilities (`bg-surface-1/2/3`), or raw palette colors (`emerald`/`rose`/`green`/`red`) that violate `PATTERNS.md` and `STYLING.md`.
