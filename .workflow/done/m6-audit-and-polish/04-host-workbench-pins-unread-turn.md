- `packages/agent-contract/src/metadata.ts` adds `pinned: { at }`, `workbench: { lastIdleAt?, viewedAt?, lastTurnOutcome? }` and `turn: { endedAt, durationMs }` to `operationalSchema`, and their nullable patch forms (per-field null for `workbench`) to `operationalPatchSchema`. `durationMs` is a finite nonnegative measure, so a sub-millisecond run keeps its value. `packages/agent-contract/README.md` states the Host ownership and the unread rule.

- `turn-duration.js` now consumes validated `CanonicalEventSchema` `run.started`, `run.completed`, `run.failed` and `run.cancelled` events. - `index.js` creates the recorder after its store writer exists and calls it from the `globalMessageStreamHub.subscribeEvent` handler directly after `sessionLineage.observe`, so a `session.updated` parent relation is known before a terminator is judged.
- `host/DOCUMENTATION.md` records the persistence owner, runId matching, subsession skip, SSE announcement, and that `unread-baseline.js` stays dormant for the retired runtime.
