# Встановлення

Оберіть застосунок під свій спосіб роботи:

- десктопний застосунок для macOS, Windows і Linux
- вебзастосунок на базі CLI, який також можна встановити як PWA
- мобільний застосунок для iOS та Android

## Веб + PWA

Для роботи сервера OhPiChamber необхідно задовольнити попередні вимоги: Node.js 24.14+ для Host Gateway, Bun 1.3.14+ у PATH для Agent Service та git.

```bash
curl -fsSL https://raw.githubusercontent.com/Shizuku-Yume/ohpichamber/main/scripts/install.sh | bash
ohpichamber --ui-password be-creative-here
```

Відкрийте URL, який вивів CLI (зазвичай `http://localhost:3000`). Введіть свій пароль UI на екрані входу, щоб увійти. Після входу ви побачите список сесій OhPiChamber. Щоб він був під рукою, скористайтеся опцією «Install» в адресному рядку браузера й додайте його як застосунок.
