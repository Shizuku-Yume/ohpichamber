# M4: Orchestration adaptation, OMP TUI parity, and feature verification

**Status:** in progress
**Priority:** high

## What this is for

The M3 migration, Post-M3 Hardening, Upstream Refresh, and OMP-Native Chat/Parity efforts wired OpenChamber's core session loop onto the Canonical API and retired the Host Session Goals supervisor in favor of OMP's native `RpcGoalController`. However, two comprehensive audits — `.workflow/research/omp-opencode-openchamber-audit.md` (with `crude-port-ledger.md`) and `.workflow/research/omp-tui-parity-audit.md` (auditing pinned OMP 18.16.0's built-in TUI in `vendor/omp/650f3a10/`) — revealed three major gaps that must be closed in M4:

1. **Orchestration & Settings Adaptation Defects (`Part A`):**
   - `workflows/agent-session.js` creates workflow branch sessions without `parentSessionId` and passes `options.agentId: agent || null`, failing `assertRootPromptAdmission` with HTTP 400.
   - `RoutingPage.tsx` and `prompt-delivery-runtime.js` still expose a root `AgentSelector` (causing HTTP 400 on `openchamber/auto`) and bind thinking controls to `model.variants` instead of `model.reasoningOptions` / `options.reasoningEffort`.
   - `DefaultsSettings.tsx` and `small-model/index.js` maintain duplicate Host overrides (`smallModelOverride`, `walkthroughModelOverride`) instead of resolving utility completions through OMP's `modelRoles` (`smol`, `commit`, `default`).
   - Residual Batch B3 / `CP-09` crude ports remain: first-message `<system-reminder>` response-style injection (`BehaviorPage.tsx`), the dead `agentToolsCodeMode` toggle, dual Host `permissionDefaultMode` / `permission-auto-accept`, hardcoded `enableLsp: false` in `worker/session.ts`, 500 `MCP_CONFIG_READ_FAILED` on hand-written `.omp/mcp.json`, `'opencode'` nav group key and ambiguous `Extensions`/`Plugins`/`Snippets` labels, and fatal `this.fail()` worker crashes on non-mutating or cleanly rolled-back `selectBranch` operations.
2. **Missing OMP 18.16.0 Built-in TUI Features & Displays (`Part B`):**
   - **Tool & Markdown Visuals (`TUI-Q1`):** `out://` mid-turn replies fail (`out.enabled`/`tuiTranscript` unset) and misrender as broken file cards; ````svg```` blocks render as raw XML instead of inline figures; numeric Markdown tables are not auto-charted; `ast_edit` diffs are dropped by `toolDiffUtils.ts`; `ast_grep`, `eval`, `lsp`, `checkpoint`, and `rewind` have no card descriptors; consecutive `read` calls flood the timeline instead of grouping into a tree; and `tool_stream_update` is dropped so tool arguments stay blank while streaming.
   - **Subagent Live HUD & Controls (`TUI-Q2`):** `worker/session.ts` ignores `TASK_SUBAGENT_PROGRESS_CHANNEL` and `TASK_SUBAGENT_EVENT_CHANNEL` and lacks `steer_subagent` / `cancel_subagent` controls.
   - **Timeline Notices, Compaction Divider & Context Gauge (`TUI-Q3`):** `WorkerProjection` drops `todo_reminder`, `ttsr_triggered`, `auto_retry_start` / `retry_fallback_applied`, `served_model_mismatch`, and `cache_invalidation`; compaction dividers lack method labels, `tokensBefore → tokensAfter` ratios, and expandable summaries; and `ContextUsageDisplay` lacks auto-compaction/speculation threshold tick marks.
   - **16 Model Roles & Settings (`TUI-Q4`):** `OmpSettingsPage.tsx` renders `modelRoles` as a raw JSON `<Textarea>` instead of visual model/effort selectors for OMP's 16 roles, and `OMP_SETTING_IDS` omits `cycleOrder`, `modelPresets`, `modelRoleStorage`, `tier.*`, `out.enabled`, `tui.render*`, and tool/buffer settings.
   - **Slash Commands, Magic Keywords, URL Autocomplete & Ghost-Text Prediction (`TUI-Q5`, `TUI-Q8`):** `worker/builtin-commands.ts` only allowlists 7 of 87 commands; composer ignores magic keywords (`ultrathink`, `orchestrate`, `workflowz`, `jevify`), per-turn token budgets (`+Nk!`), internal URL autocompletes (`skill://`, `local://`, `proc://`, `agent://`, `history://`), and post-turn idle ghost-text prompt prediction (`ComposerPredictionController`).
   - **Checkpoints/Rewind, `/btw` Branch Promotion & Plan Enhancements (`TUI-Q5`, `TUI-Q6`):** `checkpoint` and `rewind` tools (`branchWithSummary`) are not wired in `worker/session.ts`; `BtwPanel.tsx` lacks `branchFromBtw` ("Promote to Branch") and `<inject>`; and Plan mode lacks deferred mid-run entry, `plan.autosave`, and execution model selection in `PlanReviewDialog.tsx`.
   - **Background Jobs Sheet, `proc://` & Job Widgets (`TUI-Q5`):** `BackgroundShellsStrip.tsx` has no interactive Jobs Sheet for inspecting stdout/stderr/streams, sending stdin to named services, displaying `JobCaptionWriter` summaries, or rendering `JobWidgetRegistry` live metrics (sparklines, bars, meters, status grids).
   - **Autonomous Loops, `/omfg`, `/cleanse`, `/tan`, `/seance` & Advisor Watchdog (`TUI-Q7`, `TUI-Q8`):** OMP's `/loop` (`--until`/`--while`), `/omfg` (TTSR rule synthesis), `/cleanse` (parallel subagent diagnostic repair), `/tan` (background cloned session), `/seance` (historical session consult), and Advisor watchdog (`advisor/runtime.ts` + `AdvisorMessage` timeline cards) are not exposed.
3. **Orchestration Verification & Unverified Product Docs (`Part C`):**
   - Six M4 product doc pages still carry unverified warning banners from `post-m3-hardening/24` and instruct users to configure retired root agents.

## What it does

- **Part A — Orchestration & B3 Adaptation Fixes (`Tasks 01–05`):**
  - Workflows nest child sessions under `parentSessionId` and enforce `agentId: null`.
  - Auto Routing removes `AgentSelector`, selects thinking levels from `model.reasoningOptions`, and writes `options.reasoningEffort` with `agentId: null`.
  - Small-Model callers (`Session Assist`, `AI Git Commit/PR`, `Walkthrough`, `guests/generate`, auto-title) resolve models via OMP's `modelRoles` (`commit` / `smol` / `default`), retiring `smallModelOverride` and `walkthroughModelOverride` from `DefaultsSettings.tsx`.
  - `BehaviorPage.tsx` `<system-reminder>` injection, dead `agentToolsCodeMode`, and Host `permissionDefaultMode` / `permission-auto-accept` are removed.
  - Worker `enableLsp: false` is removed so OMP `lsp.*` settings work; hand-written `.omp/mcp.json` files project read-only (`managed: false`, secrets redacted) without 500 errors; `selectBranch` returns non-fatal 409 errors on cancelled or cleanly rolled-back navigation; and Settings navigation renames `'opencode'` to `'agent'` and clarifies `Guest Extensions`, `OMP Plugins`, and `Prompt Templates`.
- **Part B — OMP 18.16.0 Built-in TUI Feature & Display Parity (`Tasks 06–13`):**
  - **Tool & Markdown Rendering (`Task 06`):** enables `out://` mid-turn replies and renders them as borderless prose blocks; renders ````svg```` fences as sanitized inline SVG figures and charts numeric Markdown tables below the table when `tui.autoGraph` is enabled; adds `ast_edit` multi-file diffs to `toolDiffUtils.ts`; adds rich cards/headers for `ast_grep`, `eval`, `lsp`, `checkpoint`, `rewind`, and clickable `find` hits; groups consecutive `read` tool parts into a collapsible tree (`ReadToolGroup`); and streams incremental tool arguments via `tool_stream_update`.
  - **Subagent Live HUD, Steer & Cancel (`Task 07`):** projects `TASK_SUBAGENT_PROGRESS_CHANNEL` and `TASK_SUBAGENT_EVENT_CHANNEL` (live tool name, token usage, cost, turn count, retry countdown, nested tree), adds `subagent.steer` and `subagent.cancel` worker controls (`SubagentSchema` `'cancelled'` status), and renders a live Subagent Progress HUD tray with Steer and Cancel actions.
  - **Timeline Notices, Compaction Divider & Context Gauge (`Task 08`):** projects and renders `todo_reminder`, `ttsr_triggered`, `auto_retry_start` / `retry_fallback_applied`, `served_model_mismatch`, and `cache_invalidation` timeline cards; upgrades `session.compacted` and its timeline divider with compaction method, `tokensBefore → tokensAfter` badge, and expandable summary; and adds auto-compaction/speculation threshold tick marks to `ContextUsageDisplay`.
  - **16 Model Roles, Presets, Service Tiers & OMP Settings (`Task 09`):** replaces the raw JSON `modelRoles` textarea in `OmpSettingsPage.tsx` with visual model + thinking effort pickers for all 16 OMP roles, and adds `cycleOrder`, `modelPresets`, `modelRoleStorage`, `tier.*` (`openai`, `anthropic`, `google`, `subagent`, `advisor`), `out.enabled`, `tui.renderMermaid`/`renderSvg`/`autoGraph`, and tool/buffer settings to `OMP_SETTING_IDS` and the UI.
  - **Slash Commands, Magic Keywords, Turn Budgets, URL Autocomplete & Composer Prediction (`Task 10`):** expands allowed headless slash commands (`/handoff`, `/retry`, `/rename`, `/effort`, `/model`, `/switch`, `/fast`, `/slow`, `/prewalk`, `/force`, `/pin`, `/fresh`, `/clear`, `/dirs`, `/session`, `/memory`); adds composer shimmer and worker notice injection for `ultrathink`, `orchestrate`, `workflowz`, and `jevify` plus `+Nk!` turn budgets; adds internal URL autocomplete (`skill://`, `local://`, `proc://`, `agent://`, `history://`); and wires optional idle ghost-text prompt prediction (`Tab` to accept).
  - **Checkpoints/Rewind, `/btw` Branch Promotion & Plan Mode Enhancements (`Task 11`):** wires `checkpoint` and `rewind` (`branchWithSummary` + `rewind-report`) in `worker/session.ts`; adds `btw.branch` (`branchFromBtw` "Promote to Branch") and `<inject>` prompt steering to `BtwPanel.tsx`; and supports deferred mid-run Plan mode entry, `plan.autosave`, and execution model selection in `PlanReviewDialog.tsx`.
  - **Background Jobs Sheet, `proc://` & Job Widgets (`Task 12`):** adds an interactive Jobs Sheet modal to `BackgroundShellsStrip.tsx` with full stdout/stderr, `proc://` pipe stream inspection, stdin input for named services, `JobCaptionWriter` one-line captions, and `JobWidgetRegistry` live sparklines, progress bars, meters, and status grids.
  - **Autonomous Loops, `/omfg`, `/cleanse`, `/tan`, `/seance` & Advisor Watchdog (`Task 13`):** wires `/loop` (`--until`/`--while`), `/omfg` (TTSR rule synthesis), `/cleanse` (parallel diagnostic repair with `CleanseStatusBoard`), `/tan` (background cloned session), `/seance` (read-only historical session consult), and Advisor watchdog (`advisor/runtime.ts` + `AdvisorMessage` timeline cards).
- **Part C — Verification & Docs Closeout (`Task 14`):**
  - Runs end-to-end automated and real-provider verification across all M4 orchestration and TUI parity capabilities, removes the unverified M4 warning banners and stale root-agent copy from `packages/docs/content/docs/` across all 12 locales, and passes the full root gate.

## How it is built

Every worker capability stays in-process inside the Agent Service worker (`packages/agent-service/src/worker/`) over the pinned OMP 18.16.0 package exports (`vendor/omp/650f3a10/`), projected through JSON-safe `@openchamber/agent-contract` schemas and authorized by the Host Gateway. No `omp --mode rpc-ui` subprocess is spawned, no SDK object crosses IPC or HTTP, and Host Gatekeeper path/command/egress rules remain authoritative.

## What it must not do

- Must not re-introduce root `agentId` selection on chat, routing, scheduled tasks, multi-run, or workflows.
- Must not inject Agent Memory or `BehaviorPage` `<system-reminder>` text into prompts or system prompts (`omp-native-parity` invariant; OMP's own magic-keyword notices run only when the user types the standalone magic keyword).
- Must not silently overwrite or expose secret `env`/`headers` from unmanaged `.omp/mcp.json` files.
- Must not execute `<script>`, event handlers, `<foreignObject>`, or external network fetches inside inline ````svg```` figures.
- Must not edit `changelog/`.

## What was considered and rejected

- **Limit M4 to only OMP-vs-OpenCode differences and defer OMP TUI displays/features.** Rejected by the maintainer: users switching between the `omp` TUI and the OhPiChamber GUI expect the same model roles, tool cards, subagent controls, timeline notices, slash commands, and autonomous workflows in both surfaces.
- **Keep `smallModelOverride` and `walkthroughModelOverride` in Host `settings.json` alongside OMP `modelRoles`.** Rejected by the maintainer (Q2): unifying on OMP `modelRoles` (`smol`, `commit`, `default`) keeps a single source of truth in `config.yml`.
- **Keep `BehaviorPage` `<system-reminder>` injection and Host `permission-auto-accept`.** Rejected by the maintainer (Q3): violates `omp-native-parity` prompt purity and creates competing permission engines.

## How we will know it works

- **W1.** A workflow run started with `OPENCHAMBER_WORKFLOWS_ENABLE=1` and a branch specifying `{ agent: 'reviewer', label: 'review', schema: ... }` creates a child session with `parentSessionId` set to the proposing session, dispatches its prompt with `agentId: null` (no HTTP 400), validates the schema answer, and delivers the report.
- **W2.** In `RoutingPage.tsx`, no `AgentSelector` is rendered; category thinking options list `model.reasoningOptions`. Sending a prompt to `openchamber/auto` classifies the prompt, rewrites `providerId`, `modelId`, and `reasoningEffort` with `agentId: null`, and completes the run.
- **W3.** With `modelRoles.smol` and `modelRoles.commit` configured in OMP settings, `small-model` (`Session Assist`, `Walkthrough`, `guests/generate`) resolves `modelRoles.smol` and `gitApi` (`generateCommitMessage`, `generatePullRequestDescription`) resolves `modelRoles.commit`. `DefaultsSettings.tsx` renders no `smallModelOverride` or `walkthroughModelOverride` fields.
- **W4.** Sending the first message in a new session emits no `<system-reminder>` response-style part; `BehaviorPage.tsx`, `agentToolsCodeMode`, and `permission-auto-accept` / `permissionDefaultMode` are absent from the codebase and Settings UI.
- **W5.** `worker/session.ts` passes no `enableLsp: false` override to `createAgentSession`, so OMP's `lsp.*` settings control LSP initialization inside the worker's `cwd`.
- **W6.** When `.omp/mcp.json` is an unmanaged native OMP file (without an `openchamber` wrapper or containing `env`/`headers`), `GET /api/agent/v1/workspaces/:id/mcp` returns 200 with read-only server entries (`managed: false`) and redacted secrets instead of 500 `MCP_CONFIG_READ_FAILED`, and mutating routes refuse to overwrite it without explicit conversion.
- **W7.** A `selectBranch` / revert request where `navigateTree` returns `cancelled: true` or rolls back cleanly returns HTTP 409 without calling `this.fail()` or terminating the live session worker.
- **W8.** `SettingsView.tsx` contains no `'opencode'` nav group key, and Settings navigation displays `Guest Extensions`, `OMP Plugins`, and `Prompt Templates`.
- **W9.** A `write` to `out://` succeeds mid-turn and renders as a borderless assistant reply block (`ReplyWrite`); ````svg```` fences render as sanitized inline SVG figures and numeric Markdown tables render an auto-chart when `tui.autoGraph` is enabled; `ast_edit` renders multi-file diffs and +/- counts; `ast_grep`, `eval`, `lsp`, `checkpoint`, and `rewind` render dedicated headers/cards; consecutive `read` calls collapse into a `ReadToolGroup` tree; and `tool_stream_update` streams partial tool arguments while a tool call is being generated.
- **W10.** Active `task` subagents stream `TASK_SUBAGENT_PROGRESS_CHANNEL` and `TASK_SUBAGENT_EVENT_CHANNEL` updates (active tool name, token usage, cost, turn count, nested tree) into a live Subagent HUD tray, and the user can steer (`subagent.steer`) or cancel (`subagent.cancel` → status `'cancelled'`) an individual running subagent without aborting the parent run.
- **W11.** `WorkerProjection` projects and the chat timeline renders `todo_reminder`, `ttsr_triggered`, `auto_retry_start` / `retry_fallback_applied`, `served_model_mismatch`, and `cache_invalidation` notice cards; `session.compacted` renders a divider with compaction method, `tokensBefore → tokensAfter` badge, and expandable summary; and `ContextUsageDisplay` shows auto-compaction (`thresholdPercent`) and speculation (`speculationPercent`) tick marks.
- **W12.** `OmpSettingsPage.tsx` renders visual model and thinking-effort selectors for all 16 OMP `modelRoles` (`default`, `smol`, `slow`, `vision`, `plan`, `commit`, `tiny`, `memory`, `task`, `advisor`, `widget`, `image`, `web`, `speech`, `dictation`, `judge`), and `OMP_SETTING_IDS` exposes `cycleOrder`, `modelPresets`, `modelRoleStorage`, `tier.*`, `out.enabled`, `tui.render*`, and tool/buffer settings.
- **W13.** Headless OMP slash commands (`/handoff`, `/retry`, `/rename`, `/effort`, `/model`, `/switch`, `/fast`, `/slow`, `/prewalk`, `/force`, `/pin`, `/fresh`, `/clear`, `/dirs`, `/session`, `/memory`) execute through the `command` control; standalone magic keywords (`ultrathink`, `orchestrate`, `workflowz`, `jevify`) shimmer in the composer and inject their OMP notices; `+Nk!` sets the turn token budget; internal URL schemes (`skill://`, `local://`, `proc://`, `agent://`, `history://`) autocomplete in the composer; and idle ghost-text prompt prediction (`Tab` to accept) works when enabled.
- **W14.** Model calls to `checkpoint` and `rewind` prune the exploration branch via `branchWithSummary` and project the `rewind-report` entry; `BtwPanel.tsx` supports promoting a `/btw` exchange to a branch (`branchFromBtw`) and steering `<inject>` prompts; and Plan mode supports deferred mid-run entry, `plan.autosave`, and choosing the execution model in `PlanReviewDialog.tsx`.
