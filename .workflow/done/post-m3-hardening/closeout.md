## Key decisions & plan changes

- **Accept official registry native leaves for non-Linux targets (2026-11-04):** Accepted official registry native leaf packages (`@oh-my-pi/pi-natives-*@18.16.0`) verified by signed SLSA provenance attestation, SHA-256/SHA-512 archive integrity, and target `os`/`cpu` declarations matching `copy-manifest.json` as sufficient to resolve the native artifact packaging gate and unlock the M5 non-Linux release matrix. This supersedes the strict single-host cross-compilation source-build criterion while preserving target-platform runtime execution certification as explicitly unrun until native hosts/runners are available.
- **Defer M4 replanning to a dedicated milestone effort (2026-11-04):** Deferred M4 replanning (Task 25: verification of Goals, Assist, Routing, Session Work, Scheduled Tasks, Walkthrough, and small-model client orchestration) to a dedicated future milestone effort following the comparison audit.
- **Bundle the Agent Runtime into `@openchamber/web` (2026-10-24):** Bundled a per-platform Agent Runtime payload into `@openchamber/web` using the Electron-verified staged payload, avoiding publishing `@openchamber/agent-service`, `@openchamber/agent-contract`, or vendored OMP packages to public registries.
- **Keep Capacitor mobile in the M5 release matrix (2026-10-24):** Retained Capacitor mobile as a supported surface in the M5 release matrix, with release blocked until physical-device certification passes on a Pixel 8 (Android 15/API 35) and an iPhone (iOS 26/TestFlight).
- **Break the Guest SDK version for the private bootstrap transport (2026-10-24):** Shipped an explicit breaking version bump for the private `MessagePort` bootstrap transport (`v: 2`, package `3.0.0`, manifest `apiVersion: 1`) without backwards-compatibility shims; pre-M3 `v1` callers receive an explicit version-mismatch pane.
- **Keep isolated spaces unreleased without OpenCode runtime (2026-10-24):** Retained container and boundary infrastructure but removed in-space OpenCode CLI, plugins, and proxy; enforced an authoritative server-owned release gate (`ISOLATED_SPACES_RELEASED = false`), failing closed until an OMP space runtime is developed in a separate effort.
- **Adopt upstream-first area refresh for upstream synchronization (2026-10-27):** Based on the measured 3,288-path fork divergence from the pinned baseline, adopted periodic upstream-first area refreshes rather than commit-level cherry-picking or full-tree merges, leading directly into the `upstream-refresh` effort.

## Remaining debt & follow-ups

- **M4 replanning deferred:** Re-planning of M4 orchestration verification (Task 25: Goals, Assist, Routing, Session Work, Scheduled Tasks, Walkthrough, and small-model client verification against the canonical service) remains deferred to a dedicated future milestone effort.
- **Unrun target runtime certification:** Non-Linux desktop platforms (macOS x64/arm64, Windows x64/arm64), Linux arm64, and physical mobile devices (Pixel 8 Android 15, iPhone iOS 26) have verified native artifact staging and provenance, but runtime execution certification remains explicitly unrun until native runners, hardware, and signing credentials are provided (tracked under M5 tasks `01`–`09`).
- **Technical debt items recorded in `technical-debt.md`:**
  - `Session unread state has no OMP source`: upstream marks sessions unread from OpenCode idle/viewed states; requires a Host-owned viewed watermark on the canonical session contract.
  - `Session pins have no OMP source`: upstream pins sessions via OpenCode metadata; requires Host-owned pin state.
  - `Terminal shutdown test races its own SIGTERM record`: pre-existing test timing race under high multi-suite CPU load; requires bounded polling on the event file or extended fixture grace.
  - `Workspace session listing failure on transient supervisor errors, in-flight commands, or removed worktrees`: errors in a single workspace scope can poison the global session store status; requires workspace-level error isolation and Host worktree-archive endpoints.
  - `Session create cannot set a parent link`: canonical session create requests lack parent linkage; workflow agents and server-side fan-out run as root sessions.
  - `Root test contention flakes under multi-suite load`: process-lifecycle integration assertions in `workers.capacity.test.ts` flake under multi-suite concurrency; requires bounded state polling.
  - `Turn stats Elapsed 0.0s on turns with tool calls`: telemetry calculates elapsed duration from intermediate virtual user messages instead of canonical Turn records.
  - `Host tool errors collapse to SERVICE_UNAVAILABLE`: status-to-problem code mapping collapses 404, 409, and 499 into 503 `SERVICE_UNAVAILABLE`.
  - `Per-session warming has no Agent Service implementation`: workspace-level warming is supported; per-session warming route and controls remain unmounted.
  - `Session relocation can race worktree archive before admission`: pre-admission session relocation can race with worktree archive worker fencing; requires dedicated concurrency protection.
