# Quickstart

## Fastest path

1. Install OhPiChamber and ensure prerequisites (Node.js 24.14+ and Bun 1.3.14+ on PATH) are met (see [Install](/install/)).
2. Run `ohpichamber --ui-password be-creative-here`.
3. Open the URL the CLI prints (usually `http://localhost:3000`) and sign in with your UI password.
4. To use it from your phone, start a [tunnel](/tunnels/) and scan the QR code.

You should see the OhPiChamber session list in your browser. If it loads, you're up and running.

Use a strong UI password, especially if you plan to open the instance to the internet.

If the page doesn't load, check [Troubleshooting](/troubleshooting/).

## Which app should I use?

- use **desktop** for day-to-day work on macOS, Windows, or Linux
- use **web** for remote access and reviewing from your phone
