# Instalación

Elige la app que encaje con tu forma de trabajar:

- app de escritorio para macOS, Windows y Linux
- app web alojada por la CLI, que también puedes instalar como PWA
- app móvil para iOS y Android

## Escritorio

Descarga la última versión desde la [GitHub Releases](https://github.com/Shizuku-Yume/ohpichamber/releases/latest) y ábrela. Para Linux hay `.deb`, `.rpm` y AppImage.

## Web + PWA

Ejecutar el servidor de OhPiChamber requiere cumplir los requisitos previos: Node.js 24.14+ para el Host Gateway, Bun 1.3.14+ en el PATH para el Agent Service y git.

```bash
curl -fsSL https://raw.githubusercontent.com/Shizuku-Yume/ohpichamber/main/scripts/install.sh | bash
ohpichamber --ui-password be-creative-here
```

Abre la URL que imprime la CLI (normalmente `http://localhost:3000`). Introduce tu contraseña de UI en la pantalla de inicio de sesión para acceder. Una vez iniciada la sesión, verás la lista de sesiones de OhPiChamber. Para tenerlo a mano, usa la opción "Instalar" de tu navegador en la barra de direcciones para añadirlo como una app.
