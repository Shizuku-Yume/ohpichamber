## Progress

- Check before: on the real web UI (isolated HMR dev server, isolated data dir, DevTools context `ux05`), a sent `"你好"` prompt rendered a 235px-wide bubble with full-width action sibling and an unconditional `line-clamp-2` (display `flow-root`/`-webkit-box`, 235px max-content); the fake `[data-testid=ghost-prediction]` overlay ("What should we do next? TAB") painted over the editor while the turn was running; and with dictation active (`data-dictating="true"`) the `.oc-glass-composer` box matched no hiding rule, so the editor text and footer controls stayed at opacity 1 under the overlay. Evidence: `ux-05/baseline-measurements.json`, `baseline-bubble.png`, `baseline-dictation.png`.
- Root cause: ghost prediction was a fake static string gated by a `composer.predictions` settings fetch and an 800ms timer that never checked run state; the user bubble stretched because `UserMessageBody` was `w-full` and `line-clamp-2` (`display:-webkit-box`) pins text to max-content width while the `actionsBlock` sibling stretched the shared shell; and the dictation hiding rule only matched `.oc-surface-floating`, while the desktop composer box is `.oc-glass-composer`.
- Change: `ChatInput.tsx` drops the ghost state, timer effect, Tab/Escape branches, overlay markup and the now-unused `getSyncSessionDirectory` import, leaving `SessionSuggestionChip` as the only suggestion surface. `ChatMessage.tsx` makes the shell `flex max-w-[85%] flex-col items-end` and the bubble `w-fit max-w-full`; `MessageBody.tsx` `UserMessageBody` becomes `relative w-fit max-w-full`; `UserTextPart.tsx` applies `line-clamp-2` only when `isCollapsed && (isTruncated || textContent.includes('\n') || textContent.length > 80)`. `design-system.css` adds the matching `.oc-glass-composer[data-dictating]` rules beside the existing `.oc-surface-floating` ones (keeping `data-dictation-chain` and `.oc-dictation-overlay` visible), and `ComposerFooter.tsx` hides `ComposerModeSelector` while `dictationActive`.
- Check after: real UI re-measured on the same isolated surface. Ghost overlay absent while idle, typing and during an active turn; CSS placeholder renders and Tab/Escape no longer insert or dismiss anything. `"你好"` renders a 70px `w-fit` pill flush with the column's right edge at 1440 and 1024 widths; a two-line prompt clamps at 118px; a 274-character prompt clamps at 570px (scroll 92px) with "Show full message", and expands to 146px with "Show less"; a 57-character Chinese prompt wraps to two lines instead of stretching. With dictation recording, the editor, footer-left group, model controls and mode selector reach effective opacity 0 while the overlay and its three controls stay at opacity 1; the typed draft survives activation and Escape cancel, and the mode selector returns.

Two widths came from viewport emulation, not hardware.
