# OhPiChamber ドキュメント

OhPiChamber は、Oh My Pi (OMP) を搭載した AI コーディングエージェントのためのビジュアルな作業スペースです。コマンドラインだけで作業する代わりに、その作業を見守り、方向付ける画面を提供します。

このドキュメントでは次のことができます。

- 作業方法に合ったアプリをインストールする
- OhPiChamber を安全にリモート利用できるように開く
- 見た目をカスタマイズし、よくある問題を解決する

## OhPiChamber の用途

OhPiChamber は、AI コーディングのうち、管制室があると便利な部分のためのものです。セッションの分岐、差分レビュー、ターミナル管理、ツール進行状況の監視、プロジェクトアクションの実行、エージェントが作業している間に全体の状況を見える状態に保つことができます。
